## 📋 Sobre o Projeto

**Super Trunfo LoL** é um jogo de cartas para navegador inspirado no clássico Super Trunfo, ambientado no universo de **League of Legends**. O jogador (Invocador) enfrenta o computador (Nexus) em batalhas baseadas nos atributos de lore dos campeões de Runeterra.

Cada rodada, o jogador recebe uma carta com um campeão e precisa escolher o melhor atributo para vencer a carta oculta do adversário. Com 170+ campeões disponíveis, cada partida é única.

---

## 🎮 Como Jogar

1. Clique em **"🎲 Sortear Cartas"** para distribuir uma carta para cada lado
2. Analise os atributos do seu campeão
3. Clique no atributo que deseja usar para atacar
4. Clique em **"⚔️ Atacar!"** para revelar a carta do Nexus e ver o resultado
5. O maior valor vence a rodada e marca um ponto
6. Continue até acabar as cartas — quem tiver mais pontos vence!

---

## ✨ Funcionalidades

- ✅ 170+ campeões de League of Legends com atributos baseados na lore
- ✅ Carta do adversário oculta até o momento do ataque
- ✅ Seleção interativa de atributo para comparação
- ✅ Placar em tempo real (Invocador vs Nexus)
- ✅ Contador de cartas restantes com animação
- ✅ Embaralhamento com algoritmo **Fisher-Yates**
- ✅ Efeito de partículas animadas no fundo
- ✅ Tela de resultado final com opção de reiniciar
- ✅ Design temático do universo de Runeterra

## 🚀 Como Executar

Não precisa instalar nada! Basta abrir o arquivo no navegador:

```bash
# Clone o repositório
git clone https://github.com/ingridypinho/Super-Trunfo-de-League-of-Legends.git

# Acesse a pasta
cd Super-Trunfo-de-League-of-Legends

# Abra o arquivo no navegador
# Windows:
start inex.html

# Mac:
open inex.html

# Linux:
xdg-open inex.html
```

Ou simplesmente dê **duplo clique** no arquivo `inex.html`.
